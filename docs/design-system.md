# Design System

## Purpose

Define the visual and interface rules for the Zexa Media website before component development.

## Design Direction

The website should feel modern, sharp, premium, and practical. It should communicate growth, clarity, and digital confidence without feeling generic or overly decorative.

## Interface Principles

- Prioritize clarity over visual noise.
- Use strong hierarchy and generous spacing.
- Keep service information easy to scan.
- Use cards only for repeated content or structured groups.
- Avoid generic agency-template clutter.

## Color Direction

Final colors should be confirmed from brand assets. Until then, use a restrained palette with:

- High-contrast dark text
- Clean light backgrounds
- One strong accent color
- Subtle neutral surfaces

Avoid overusing a single hue across the entire interface.

## Typography Direction

- Use clear modern sans-serif typography.
- Keep headings confident and concise.
- Use readable body text sizes.
- Avoid overly compressed letter spacing.

## Layout Rules

- Mobile-first responsive layout.
- Strong desktop spacing without making sections feel empty.
- Clear content bands for major sections.
- Consistent max-width containers.
- No nested cards.

## Component States

Every interactive element should include:

- Default state
- Hover state
- Focus-visible state
- Disabled state where relevant

## Accessibility Baseline

- Semantic HTML
- Sufficient color contrast
- Keyboard-accessible navigation
- Descriptive alt text for meaningful images
- Visible focus indicators
