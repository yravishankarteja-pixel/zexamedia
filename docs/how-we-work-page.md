# How We Work Page

## Current Status

The website now has a dedicated `/how-we-work` page that explains Zexa Media's remote growth marketing workflow.

## Problem

Global visitors need more than service pages. They need to understand:

- How the first audit works.
- What access is needed.
- How onboarding is handled.
- How remote communication works.
- How reporting is shared.
- How Zexa avoids unrealistic promises.

## Exact Fix Implemented

Created `/how-we-work` with:

- Remote audit workflow.
- Priority roadmap explanation.
- Safe onboarding and access control.
- Execution sprint model.
- Reporting rhythm.
- Optimisation loop.
- Remote trust cards.
- Onboarding checklist.
- Communication cadence.
- FAQ schema.
- WebPage schema.

Added links from:

- Header navigation.
- Footer navigation.
- Sitemap.

## UX Reasoning

The page acts as a trust bridge between service interest and audit booking. It helps worldwide buyers understand how Zexa can work with them without being in the same city or country.

## Verification Checklist

- `/how-we-work` is linked in the header.
- `/how-we-work` is linked in the footer.
- `/how-we-work` is included in the sitemap.
- Page copy is global, clear and practical.
- No fake claims or guarantees are used.
